# DSA Practice Problems

Organize your practice problems by topic in the respective directories.

## Directory Structure

```
problems/
├── arrays/              # Array problems
├── linkedlist/         # Linked list problems
├── stack/              # Stack problems
├── queue/              # Queue problems
├── trees/              # Tree problems (BST, Binary Tree, etc.)
├── graphs/             # Graph problems (BFS, DFS, shortest path, etc.)
├── sorting/             # Sorting algorithms
├── searching/           # Searching algorithms
├── dynamic-programming/ # DP problems
├── strings/             # String manipulation problems
├── math/                # Mathematical problems
├── bit-manipulation/    # Bit manipulation problems
├── hash-tables/         # Hash table problems
├── heaps/               # Heap problems
├── backtracking/        # Backtracking problems
├── greedy/              # Greedy algorithm problems
└── divide-conquer/      # Divide and conquer problems
```

## Usage

Create your solution files in the appropriate topic directory. For example:
- `arrays/two-sum.java`
- `linkedlist/reverse-linked-list.java`
- `trees/binary-tree-traversal.java`

Happy coding! 🚀
